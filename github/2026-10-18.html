六、机会分析

机会 1：AI 求职代运营服务（需求最硬）

是什么：帮客户部署+定制 ai-job-search：简历改写、岗位匹配、海投跟踪、面试准备，打包成“求职加速”服务。

为什么值得做：求职是强付费意愿场景；该仓库 fork 1.7 万说明真有人用，但普通人跑不通，需要有人代劳。

第一步：本周自己跑通 ai-job-search 全流程，录一条“agent 一天投 50 份简历”演示视频发 B 站/视频号验流量。

机会 2：本地语音代工（成本结构最优）

是什么：有声书/课程配音/短视频配音代工，全本地跑 VoiceStudio，零 API 成本。

为什么值得做：VoiceStudio 连续两天日增破 2k 验证需求；AGPL-3.0 只限制分发代码，做服务不受影响。

第一步：跑通 VoiceStudio 中文长文本配音，生成 3 分钟样片当作品集，去猪八戒/淘宝挂“AI 配音代工”。

机会 3：科研 skills 本地化（垂直差异化）

是什么：scientific-agent-skills 宣称 25 万科学家在用——给国内实验室/药企做中文科研 skills 定制（文献综述、数据分析管线）。

为什么值得做：垂直 skills 避开通用 skills 红海；你的 AI 落地工程能力正好对口。

第一步：做 1 个中文文献综述 demo skill，发到科研/开发者社群验需求。

机会 4：老代码库 AI 审计服务（早期窗口）

是什么：用 xerj 给企业做代码库索引+安全审计+知识问答，存量代码是每个公司的痛。

为什么值得做：xerj 总星仅 7,816 还在早期，差异化（省 token/省 infra）讲得清；你是老 Java 代码的行家，审计有说服力。

第一步：拿自己的一个老项目（比如某个 Java 仓库）跑通 xerj 索引+问答，做一页效果对比（grep vs xerj 的 token/时间）。
