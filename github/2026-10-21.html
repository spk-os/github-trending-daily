六、机会分析

机会 1：中文求职 agent 定制包（最对口）

是什么：ai-job-search 的 portal CLI 只覆盖丹麦招聘站；做中文版：BOSS 直聘/拉勾抓取 + 中文简历 LaTeX 模板 + 面试 workflow，打包成 Claude Code skill。

为什么值得做：日榜 #1 两连庄验证需求真实；国内求职季焦虑强、暂无中文版；skill 纯 Markdown 交付轻、可复制。

第一步：本周 fork ai-job-search 跑通 /setup+/apply，写一份中文适配可行性笔记，发 1 条 B 站/视频号演示视频验流量。

机会 2：企业代码安全审计代跑

是什么：基于 cloudflare/security-audit-skill，给中小团队做代码安全审计代跑，按次收费。

为什么值得做：大厂官方 skill 背书可信度高；企业有合规需求但缺安全人手；审计报告是标准化交付物，个人可独立交付。

第一步：用 skill 给自己 star 的一个开源项目跑一次完整审计，输出一份中文报告样板，作为获客物料。

机会 3：企业 agent token 降本审计

是什么：headroom/context-mode 同周上榜说明 token 成本是真痛点；给已在用 coding agent 的小团队做用量审计+压缩方案，按省下的钱分成收费。

为什么值得做：压缩 20-98% 直接等于省钱，企业为降本付费意愿最强；你有 OmniRoute 网关实操经验，懂用量计量。

第一步：先用 headroom 给自己的 agent 用量做一次压缩前后对比，输出数据页作为咨询案例。

机会 4：“老代码库 X 光”接手审计包

是什么：把 graphify 包装成接手老项目/外包代码的审计工具：AST 知识图谱 + agent 解读，输出架构报告。

为什么值得做：接外包第一痛点是读不懂老代码；知识图谱每条边可解释，是相对黑盒 RAG 的差异化卖点。

第一步：拿一个公开老项目跑 graphify，输出一份“代码库 X 光报告”样板，去程序员客栈挂服务验单。

明确不跟：rea（依赖商业逆向工具、法律灰色地带）、AnyPS5（索尼法律风险悬顶）、Kronos（半年停更、吃灰型收藏）、ruflo（版本号 3.59 高频发版、API 不稳定）、dsh-purge（jailbreak 工具、合规风险）——都是围观型热点，不硬凑。
