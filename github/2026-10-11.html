六、机会分析

机会 1：企业 agent skills 定制包（最对口）

是什么：企业缺“按自家流程定制的 skills”（销售话术/代码规范/审批流/SOP），部署到员工的 Claude Code/Cursor。

为什么值得做：你的强项正是 AI 落地工程；skills 纯 Markdown 交付轻、可复制；Makeitfuture 靠 n8n 代搭建交付 15,000+ 方案，验证有人买单。

第一步：本周把 diagram-design、ppt-master 跑通，录 3 条中文演示视频发 B 站/视频号验流量，再去猪八戒挂“企业 AI 提效 skill 定制”（2,000-5,000 元/包）。

机会 2：“文档→交付物”代做（需求最硬）

是什么：用 ppt-master（文档→原生 pptx）+ hyperframes（HTML→MP4）接单：BP 美化、课程 PPT、产品短视频。

为什么值得做：客户为“成品”付费；全用现成开源工具，成本只有模型 API 费。

第一步：给自己做 10 页服务介绍 PPT + 30 秒介绍视频当作品集，猪八戒定价 300-800 元/份先跑 5 单。

机会 3：“AI 网关 + 上下文成本优化”部署（利润最厚）

是什么：卖“网关部署 + 用量审计 + 压缩调优”一次性服务 + 年维护费，不卖代码。

为什么值得做：你懂网关和 Docker；“帮你省 30% token 账单”是可量化的 ROI，比卖工具好卖。

第一步：VPS 上 Docker 部署 context-mode（ELv2 许可：只做部署、不分发代码），跑一周记录省了多少 token，做成一页 PDF 案例。

明确不跟：rea（依赖商业逆向工具、有法律灰色地带）、AnyPS5（索尼法律风险悬顶、仅 1 款 2D 小游戏验证可玩）、artcraft（叙事泡沫、产品远未可用）——三者都是围观型热点，普通开发者无套利空间，不硬凑。
