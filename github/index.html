六、机会分析

机会 1：computer use 落地服务（最直接）

是什么：用 vercel-labs/agent-desktop 给中小企业做桌面自动化：报表整理、系统录入、开票流程等按流程包收费。

为什么值得做：agent-desktop 单日 +2,470 说明工具已可用；企业为“省人工”付费，不为工具本身付费。

第一步：本周在自己电脑上用 agent-desktop 跑通一个真实流程（如自动整理下载文件夹并填表），录屏当第一个案例。

机会 2：去 AI 味与设计审计 skills 包

是什么：把 hallmark、impeccable 这类“去 AI 味、设计审计”能力打包成 Claude Code skill，卖给内容团队与设计团队。

为什么值得做：hallmark 周 +7,622 证明客户怕 AI 味是显性需求；skill 纯 Markdown 交付轻、可复制。

第一步：先用 hallmark 与 impeccable 给自己 3 篇旧文、3 张旧页面做一遍审计，输出前后对比页当作品集。

机会 3：短视频自动化代做

是什么：用 MoneyPrinterTurbo 加 scenario-labs/skills，给本地商家与课程号做“主题→成片”代运营，按条收费。

为什么值得做：MoneyPrinterTurbo 总星 13.9 万验证需求；客户为成片付费，工具成本只有模型 API 费。

第一步：先给自己做 3 条 30 秒短视频，测成片质量与单条耗时，达标后再定价接单。

明确不跟：kimi-k3-in-c（2.78T 塞进 8GB 是极端量化演示，别当生产推理方案）、90DaysOfDevOps（近 5 个月无更新，老路线图只作参考）、照搬 gstack 名人配置（23 个角色未经自己验证别直接上生产）——三者围观即可，不硬凑。
