六、机会分析

机会 1：去 AI 味审查服务（最贴合本周主线）

是什么：用 impeccable / hallmark 的思路，给客户的 AI 生成页面做“去 AI 味”审查与改版：审美、排版、文案三项打分并出修改清单。

为什么值得做：周榜双雄合计周增 2.4 万，需求已被验证；且与本周在做的去 AI 味确定性检测直接复用。

第一步：先拿自己的日报页面与一个客户页面跑一遍审查清单，整理成一页检查表，发到猪八戒挂 500-1,500 元/次的审查服务。

机会 2：agent 记忆部署包（复用 claude-mem 热度）

是什么：帮小团队部署 claude-mem 这类跨会话记忆：装好、接好 Claude Code / Codex、定好压缩策略与隐私边界。

为什么值得做：claude-mem 总星破 10 万但部署仍需动手能力；卖部署 + 调优，不卖代码，交付轻。

第一步：在自己机器上完整部署一次并记录耗时与坑点，做成一页部署说明，再去程序员客栈挂服务。

机会 3：SEO agent skill 定制（垂直缺口）

是什么：参考 claude-seo 的 26 子 skill 结构，给中文企业做 SEO + GEO（AI 搜索可见性）skill 包：技术 SEO 检查、llms.txt、结构化数据。

为什么值得做：AI 搜索正在改写流量入口，中文企业这块几乎空白；skill 纯 Markdown 交付，可复制。

第一步：先给自己的日报门户做一份 llms.txt 与 SEO 检查清单当样板，再找 2 家小企业免费试点换案例。

明确不跟：dsh-purge（破甲/jailbreak 方向，只作提示词注入防御研究参考，不跟进）、TradingAgents（只作技术研究，不做实盘相关服务）、ziwei-doushu（玄学变现敏感，只看不跟）、t3code（仓库描述为空、定位未核实，先核实再判断）——四者都不硬凑机会。
