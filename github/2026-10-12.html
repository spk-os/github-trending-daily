六、机会分析

机会 1：“行业规范→skill”垂直定制（小而硬）

是什么：把某个行业的术语规范、写作标准、审核清单做成 Claude Code/Cursor skill 包，卖给该行业的团队。

为什么值得做：asd-ste100-skill 把航空受控英语规范做成 skill 都能周增 936——证明小众规范技能化有真实需求；交付纯 Markdown，轻、可复制，正对你的 AI 落地工程强项。

第一步：先挑一个你熟的规范（如中文技术文档写作规范）做成免费 skill 发 GitHub 验星，再去程序员客栈挂“行业 skill 定制”服务页。

机会 2：低显存本地 LLM 私有化部署

是什么：用 airllm 给只有老显卡/低配机的中小企业做本地大模型部署：数据不出内网，4-6GB 显存可跑 70B 推理与 LoRA 微调。

为什么值得做：“数据不出门”是中小企业上 AI 的第一顾虑；airllm 把硬件门槛打到一张老卡，部署+调优是一次性收费 + 年维护的标准服务形态。

第一步：在自己机器上跑通 airllm + 一个 70B 量化模型，记录显存占用和生成速度，做成一页 PDF 案例再谈客户。

机会 3：实时态势大屏定制（OSINT 可视化）

是什么：基于 gods-eye-view 的 3D 地球 + 实时航班/卫星/天气数据，给物流、安防、展会客户做定制态势大屏。

为什么值得做：项目已开源且 MCP 化，接 agent 问答是现成卖点；大屏类项目客单价高、交付边界清晰，适合个人接单。

第一步：本地跑通 gods-eye-view，把数据源换成深圳本地航班/港口信息，录 30 秒演示视频当作品集。

明确不跟：rea（依赖商业逆向工具、法律灰色地带）、AnyPS5（索尼法律风险、仅 1 款小游戏验证）、artcraft（争议叙事泡沫、无新版支撑）、Apollo-11（纯怀旧）——均为围观型热点，不硬凑。
