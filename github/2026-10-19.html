六、机会分析

机会 1：本地语音配音/有声书代工（最直接）

是什么：用 VoiceStudio（646 语言、全本地、开源）接单：短视频多语配音、有声书制作、课程本地化。

为什么值得做：客户为成品音频付费；本地跑 = 零 API 成本，边际成本只有电费；fork 8,258 说明二次开发需求旺。

第一步：本机 Docker 跑通 VoiceStudio，做 3 条中英互配 demo（30 秒/条）发 B 站/视频号验流量，再挂猪八戒"AI 配音"（200-800 元/单）。

机会 2：中文垂直 skill 包（生态红利）

是什么：三大厂商同周推插件目录，"skill 商店"正在成型；做中文场景 skill（电商客服话术、小程序开发规范、SEO 文案）。

为什么值得做：纯 Markdown 交付、可复制；分发渠道（Claude Code 插件市场/skills.sh）已铺好，先发者吃流量。

第一步：复刻 diagram-design 的分发模式（SKILL.md + 多平台 manifest），本周先做 1 个"中文 PPT 大纲生成" skill 上架试水。

机会 3：求职 agent 中文版（需求最痛）

是什么：ai-job-search（+2,232 日榜第一）验证了"求职自动化"需求；做中文版：解析 BOSS/智联 JD、LaTeX 中文简历、自动求职信。

为什么值得做：应届生/转行人群付费意愿强；本地跑解决隐私顾虑；国内尚无头部中文版本。

第一步：fork 后先做 JD 解析 + 中文简历模板，打包"7 天自动投递"服务，小红书/猪八戒测 5 单（300-600 元/单）。
