六、机会分析

机会 1：企业 agent skills 定制包（最对口）

是什么：按企业流程定制 skills（销售话术、代码规范、审校清单），打包交付。

为什么值得做：skills 霸榜证明需求真实，企业缺的不是模型，而是落到自家流程的 skill；mattpocock 合集 31 万星说明市场教育已完成。

第一步：本周把 hallmark（去 AI 味）与 impeccable（设计词汇）跑通，录 3 条中文演示发 B 站/视频号验流量，再挂“企业 AI 提效 skill 定制”。

机会 2：多 agent 记忆与管控部署

是什么：给小团队部署 claude-mem + t3code + worktrunk 的多 agent 工作流。

为什么值得做：记忆与管控是本周最痛的点，个人开发者和小团队缺开箱方案，日周双榜已验证需求。

第一步：先在自己工作流跑通 claude-mem + worktrunk 并行开发，整理成一份部署清单，再接 1-2 单小团队部署。

机会 3：本地推理降本方案

是什么：用 colibri / FreeToken 给有数据主权要求的客户搭本地推理。

为什么值得做：数据不出域是硬需求，纯 C 零依赖 MoE 流式加载把硬件门槛打下来，桌面端方案正当红。

第一步：在 PC 上跑通 colibri 加载一个 MoE 模型并测速，录演示，作为“本地部署”服务的第一块样板。

明确不跟：Kronos（金融预测模型、无新进展、不碰实盘相关）、TradingAgents（周榜在列、只作技术研究、不做实盘服务）、heretic（改模型行为去审查、合规与效果边界不明、只围观）。
