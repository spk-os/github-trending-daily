三、近一周趋势分析

1. Agent Skills 从“写代码插件”变成全行业 agent 能力封装标准

本周 skill 相关上榜 7 个以上，覆盖代码、图表设计、iOS、CAD、知识工作、Cursor 插件规范。mattpocock/skills 日周双榜、28 万 star，已是水电煤。

2. Agent 能力边界向外扩

逆向（rea）、上网（Agent-Reach 周 +7084）、视频渲染（hyperframes 周 +4003，HTML 写代码渲染视频、为 agent 而生）、CAD（text-to-cad）、持久记忆（claude-mem 周 +3850）、agent 组网（openrig）。“给 agent 装手和眼睛”是本周最热的叙事。

3. 大厂下场做开源 agent 工具链

阿里（open-code-review）、Anthropic（官方插件库）、Epic（raddebugger 原生调试器）都在发力，说明这已不是极客玩具，而是基础设施卡位战。

4. 两个反常识信号

一是 AnyPS5（周 +15539）、openGym（健身追踪，周 +6749）这种硬核/出圈题材依然能爆，社区传播红利还在；二是 litellm（2023）、artcraft（2022）靠持续迭代重回榜单——“长期维护”本身就是护城河。

四、热点总结

本周 GitHub 只有一个真正的主题：Agent Skills 生态大爆发。从 28 万 star 的通用 skill 仓库，到图表、iOS、CAD、知识工作等垂直 skill，再到 Anthropic 官方下场定标准，skill 正在成为 agent 时代的“应用商店”。与此同时 agent 的能力边界在快速外扩——逆向、上网、视频、CAD、持久记忆，昨天还只是 demo 的东西正在被封装成可复用的 skill。对你来说最直接的信号是：网关（litellm 回春）+ 代码评审（阿里入场）+ skill 中文生态空白，三件事都指向“帮别人把 agent 落地”这个生意。
