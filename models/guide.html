1、0、新手 30 秒：模型到底是什么

模型就是一个“读过海量文字、图片、代码后学会接话的程序”。你给它一段输入，它按学到的规律续写最可能的内容：聊天、写代码、做题、看图说话、生成图片视频，都是同一种能力在不同输入输出上的表现。

一句话记住：模型 = 底座能力 + 使用方式。底座决定上限，提示词、工具、检索和工作流决定你实际拿到的下限。

2、1、分类地图：先分清你要的是哪种模型

先看输入输出，再看任务。同一家厂商的一个系列，往往同时覆盖下面多类。

按什么分类别代表与说明
输入输出纯文本（LLM）最常见的聊天、写作、代码模型，如 GPT、Claude、DeepSeek、Qwen
输入输出多模态能同时看图、读文档、听语音，如 Gemini、Qwen-VL、GPT 多模态版
输入输出图 / 视频生成文生图、图生视频，如 FLUX、Qwen-Image、LTX、Wan、Kling、Seedance
输入输出语音识别（ASR）与合成（TTS），如 Whisper 系、Parakeet、Qwen-Audio、本地听写 hex/Handy
输入输出向量（Embedding）把文字转成数字向量，用于搜索与 RAG，如 Qwen3-Embedding、BGE-M3、EmbeddingGemma
任务聊天 / 写作通用对话、润色、翻译、摘要
任务推理（Reasoning）先想再答，数学、科学、长链路任务更强，常标 thinking / 高推理档位
任务代码 / Agent写代码、改仓库、自己调用工具完成任务，如 Claude Code、Codex、Qwen-Coder
任务检索增强（RAG）先查你自己的资料再回答，配向量模型 + 知识库，适合企业内部问答

4、3、型号命名解码：后缀比名字更重要

型号名一般由“系列 + 档位 + 日期/尺寸”拼成。读不懂型号，九成是被后缀绕晕了。

名字里的成分意思例子

Carbon / ArgonGemini 4 档位：Carbon 高于 ArgonGemini 4 Carbon（high）AA 指数 59 居首
Astra / Sol / Terra / LunaGPT-6 档位：Astra 旗舰、Sol 次旗舰、Terra 均衡、Luna 轻量GPT-6 Astra（max）AA 指数 57
Max / Pro该系列最强档Qwen3.8-Max、DeepSeek-V4-Pro、Kimi K3.1 Pro
Flash / Lite / Mini轻快档：便宜、快、能力次一档GLM-5.3-Flash、Gemini 3.8 Flash
27B / 8B / 0.6B参数量级：B = 十亿参数；数字越大通常越强、越吃硬件Qwen3.8-27B、Qwen3-Embedding-0.6B
A3B / A23BMoE 的激活参数：总量大、每次只激活一小部分375B A23B：总量 375B，每步激活 23B

避坑：不要只比名字。GPT-6 Astra（max）和 Astra（low）可能是同一个模型的不同档位，分数能差 10 分以上；先看档位，再看分数。

5、4、常用词：20 个词讲清行话

词人话解释
参数量模型里可调的数字个数。越大通常越能记住更多知识，但不等于越聪明；还要看训练数据与架构
MoE（混合专家）模型里有很多“专家小组”，每次只请几个专家干活：总量可以很大，实际计算量可控
上下文窗口一次能“记住”多长的输入，单位是 token。1M 上下文约等于几十万字量级（因语言与分词而异）
Token模型切分文字的最小单位。中文大体 1 token 约 1 个汉字上下，英文 1 token 约 0.75 个词，都是约数
量化（Quantization）把模型精度压低（如 Q4）换体积与速度：Q4 约 0.6GB/每十亿参数，质量损失通常很小
GGUF本地运行最常见的模型文件格式，Ollama、llama.cpp、LM Studio 都吃
蒸馏大模型当老师，教小模型：小模型便宜好跑，但天花板低于老师
微调（Fine-tune）在通用模型上再用自己的数据练一轮，让它更懂某个行业或某种格式
RAG回答前先查资料库：模型 + 向量检索 + 你自己的文档，适合“不能瞎编”的场景
Agent / 智能体不只回答，还能自己规划、调用工具、改文件、跑流程完成任务
MCP让模型接外部工具的标准插口：接上后模型能查数据库、发帖、操作软件
工具调用（Function Calling）模型输出结构化指令，让程序去执行，而不是只输出文字
幻觉模型一本正经地编造：人名、数字、引用都可能现编，关键信息必须核对
开源权重权重文件公开可下载、可本地跑；不等于“完全免费商用”，要看许可证
推理档位让模型想多久：档位越高答得越稳、越贵、越慢

6、5、开源、闭源、开放权重：别被“开源”二字骗了

三句话区分：闭源 = 只能调 API，看不见权重；开源权重 = 能下载、能本地跑；免费 API ≠ 开源。

类型含义商用注意
闭源GPT、Claude、Gemini 旗舰：只给 API按量付费，数据要出境到厂商，自己无法改模型
开源权重（宽松）Apache-2.0 / MIT：Qwen、DeepSeek 部分、Llama 系部分一般可商用，但仍需读该版本 LICENSE 原文
开源权重（自定义）厂商自拟许可：GLM、MiniMax、Mistral 部分版本有的限规模、限用途，商用前必须读原文
社区许可Llama 社区许可等：有附加条件大公司用量、再分发可能有额外条款
红线：本篇不替任何许可证背书。商用前以仓库根目录 LICENSE 原文为准，日报里凡写“可商用”均指该版本当时的公开口径。

7、6、测评怎么看：榜单是参考，不是判决

榜单只能参考，不能当真理。同一模型在不同榜上排位能差十几名，原因多半是版本、档位、语言不同。

榜单它测什么怎么用
AA 智能指数 v5（Artificial Analysis）9 项自动评测综合：知识工作、编程、科学、通用看综合技术实力；注意 v5 分数不能和旧版直接比
LMArena / Arena真人盲测投票 Elo看真实用户偏好；主观、易受风格影响
SuperCLUE中文综合能力：数学、科学、代码、智能体、指令遵循、幻觉控制看中文场景；国产模型在此榜普遍更高
MTEB向量模型榜：检索、分类、聚类等 100+ 任务选 RAG 嵌入模型只看它；分英文 v2 与多语 v2
OpenRouter 用量榜真实 API 调用量看市场接受度；便宜模型天然占优
HF 趋势 / 下载量社区下载与点赞看开源热度；下载量是累计值，不是当日新增
榜单陷阱三件套：①同一模型多档位多行，别当成多个模型；②英文榜与中文榜排名不同是常态；③新版发布一周内的分数最不稳，等两周再信。

10、9、前沿方向与个人机会：盯什么、做什么

  • Agent 技能化：SKILL.md 成为事实标准，Anthropic、Cursor、Google 都在推官方技能目录——给别人写技能、做技能包是可售产品。
  • Agent 记忆与上下文工程：claude-mem 等项目总星已破 10 万，记忆层独立成赛道。
  • 端侧全模态：LiquidAI LFM3 一次出 1.7B 语言 + 视觉 + 音频三条线，手机与电脑端侧助手正在变便宜。
  • 本地语音：Whisper 系之外，NVIDIA Parakeet、hex/Handy 让个人电脑离线听写、实时转录成为日常工具。
  • 模型选型与成本网关：企业有几十个模型要管，选型咨询、网关接入、用量审计是现成服务缺口。
  • 垂直微调与量化分发：把开源模型微调到某个行业、打包成 GGUF 分发，是小团队可做的生意。

12、11、Hugging Face 模型卡 90 秒读法本期更新

Hugging Face 是模型界的 GitHub：每个模型就是一个仓库，地址是 huggingface.co/组织/模型名，比如 Qwen/Qwen3.8-27B。模型卡就是这个仓库的 README.md，顶部还有一段 YAML 设置，真正有用的信息全在卡片和文件列表里。

先看什么在哪看怎么判断
发布组织地址斜杠前面官方组织优先：Qwen、meta-llama、deepseek-ai、mistralai、nvidia 等；第三方名字要看它是不是知名转换者
pipeline_tag（任务标签）卡片顶部标签text-generation=纯文本；image-text-to-text=图文对话；automatic-speech-recognition=语音识别；text-to-image=文生图；sentence-similarity=向量嵌入
license（许可证）卡片顶部Apache-2.0/MIT 最宽松；Llama、Qwen 大模型等自定义许可要读原文；空白或现编的直接放弃
base_model 与关系卡片 YAMLbase_model_relation 会写明：quantized=量化版、finetune=微调版、adapter=适配器、merge=合并版；先确认底座是不是你要的官方模型
library_name卡片顶部transformers=原始权重（safetensors）；gguf=本地量化版；diffusers=图/视频生成
下载量 / 点赞 / 更新日期卡片右侧与列表下载量是累计值，老模型天然高；点赞可刷；更新日期比两者更重要，半年没更新的要警惕

90 秒五问，答不上来就别下：①谁发的，是官方还是知名转换者？②许可证能不能商用？③名字是 Instruct（能聊天）还是 Base（只能续写）？④文件多大、什么格式，自己的硬件装不装得下？⑤卡片有没有一句话讲清用途与限制？

再点 Files and versions 标签：这里是真正的权重文件、config、tokenizer，以及完整版本历史（可以回滚旧版）。GGUF 仓库里一个模型常有十几个量化文件；多模态模型还要一个 mmproj 文件（视觉投影），只下主文件、漏了 mmproj，看图功能就用不了。

安全红线：下载的模型文件就是要在你电脑上运行的软件。卡片空白、只有两句话描述、下载量只有两位数、许可证含糊的仓库，直接放弃，只认官方组织和知名转换者。

Qwen3.62026-0427B、35B-A3B；主打稳定与真实编码体验
Qwen3.82026-0827B 是唯一单卡友好的开源权重（Apache-2.0）；Flash-Next（125B-A6B）与 2.4T-A95B 旗舰要大基础设施；Max、Flash、Omni-Flash 主要是 API 服务，不是下载权重
  • 同系列尺寸越大通常越强，但硬盘、显存、速度代价同步涨：MoE 要同时看总量（决定硬盘）与激活参数 A（决定计算量），35B-A3B 的硬盘是 35B 的量，算力是 3B 的量。
  • 日期后缀（2507、0902、1017）是版本快照：新版不一定在你的任务上更好，换版前先看自己任务的榜单与实测。
  • 同一模型在不同地方名字不同：HF 仓库叫 Qwen/Qwen3.8-27B，Ollama 里叫 qwen3.8:27b（打包后的标签，约 18GB），下载前先对上底座，别下错量化者的改版。
  • GGUF 变体怎么选：官方仓库只有原始权重，想本地跑要找 GGUF 版，常见转换者有 unsloth、bartowski、AtomicChat、byteshape；先核对 base_model 是官方模型，再选量化档——Q4_K_M 是默认均衡档，Q8_0 更准更占地，IQ 系列更小但更糊；带 -Uncensored、-abliterated 后缀的是改过行为的版本，别当原版用。

拿 Qwen3.8-27B 当标尺（官方卡 + 第三方实测）：64 层、上下文 262,144 tokens；Q4_K_M 约 16.8–18GB，Q8_0 约 29GB，IQ2 约 10.7GB；Ollama 包约 18GB，24GB 显存档的首选之一。

14、13、三步找到适合自己的模型本期更新

没有“最好”的模型，只有“在你的硬件、预算、任务下够用”的模型。按下面三步走，半天就能定下来。

步骤做什么怎么定
第 1 步：定场景（单选）聊天写作 / 写代码 / agent 干活 / 中文客服 / 看图说话 / 语音 / 内部资料问答 / 图视频生成场景决定 pipeline_tag 与第 7 章的候选，别用聊天模型硬做检索，也别用纯文本模型做看图
第 2 步：定约束（填空）硬件：显存/内存多少？联网：能不能出境、能不能联网？预算：API 按 token 付还是本地一次性投入？商用：许可证允不允许？四项有一项卡住，候选直接砍半；离线 + 商用 + 16GB 内存，答案基本只剩 8B–14B 开源权重
第 3 步：对榜单 + 实测旗舰能力看 AA 指数，中文看 SuperCLUE，便宜大批量看 Flash 档，离线看 HF 下载榜，检索看 MTEB榜单只筛出 2–3 个候选，最后必须实测：准备 10 条自己的真实任务，同一提示词跑候选，记答对率、速度（tok/s）、成本三项

三个现成答案（2026-11-03 的档位与假设，供抄作业，换硬件要重算）：16GB 笔记本日常聊天写作，选 Qwen3 14B 或 Gemma 4 12B（约 8–9GB）；24GB 显存想干活（代码 + agent），选 Qwen3.8-27B 的 Q4_K_M（约 18GB，ollama pull qwen3.8:27b）；公司内部资料问答，用 Qwen3-Embedding-8B 做检索 + 任意旗舰 API 做回答，分开选，别指望一个模型全包。

流程先于尺寸：先用小尺寸跑通“提示词 → 工具 → 输出格式”全流程，流程通了再升级尺寸；流程不通，70B 也救不了。
