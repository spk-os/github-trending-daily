五、接单切入点

飞书 RAG Agent + MCP 网关：今日新增的两条 AI 单正中用户强项

客栈今日新增飞书知识库 RAG 智能问答 Agent（深圳，17,400 元/月）与 Agent 工作流编排平台 / MCP 工具网关（成都，13,050 元/月），都是 n8n + Dify + 网关的标准打法；AI 类已连续七日出现，需求侧稳定。

第一步：把“飞书知识库 RAG 问答 + MCP 工具网关”写成一页服务单（验证型 3–8 万元），发给之前咨询过 AI 落地的客户或挂到客栈主页作品栏。

客栈按月雇佣主流价升至 13,050 元/月，低价 3,262 档消失

今日 30 张名片按月雇佣价 6,525–32,625 元/月，主流 13,050 元/月（6 张），6,525 元档 7 张最多；昨日新出现的 3,262 元低价档今日已无，价格中枢上移，进整包报价可对标 13,050 元/月。

第一步：整包报价时以 13,050 元/月为人力成本锚点折算，一个月工作量的验证型 AI 单不低于 3 万元报价。

猪八戒 ¥4,800 档升至 TOP7：高价档仍能打，AI 功能是溢价点

榜单 TOP7 由 ¥3,500 换成 ¥4,800（小程序定制设计 + UI 源码），¥3,500 AI 交友分销档退至 TOP8；高价档轮换守榜说明买家愿为“设计 + 源码 + AI 功能”付更高价，小程序报价应把 AI 功能单列一档。

第一步：小程序报价单保留“AI 功能包（交友匹配 / 智能客服）：+1,500–3,500 元”一行，下一个咨询小程序的客户直接按此报。
